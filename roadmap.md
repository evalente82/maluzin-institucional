🗺️ Roadmap: Institutional Site High-End
Status Atual: 🟢 Definição de Stack & Configuração de IA (Concluído)

🏗️ Fase 1: Fundação & Infra (DevOps First)
Objetivo: Deixar o terreno pronto para automação total.

[ ] Setup Inicial: Iniciar projeto com Vite + React + TypeScript.

[ ] Tailwind Config: Configurar paleta de cores premium, fontes (Google Fonts) e breakpoints responsivos.

[ ] GitHub Repo: Criar repositório e configurar git.

[ ] CI/CD Pipeline: Criar .github/workflows/deploy.yml para deploy automático no GitHub Pages ou Vercel.

[ ] Estrutura de Pastas: Organizar /components, /assets, /styles e /hooks.

🎨 Fase 2: Design System & Core UI
Objetivo: Garantir que o site seja "maravilhoso" e consistente.

[ ] Layout Base: Criar Navbar (Glassmorphism) e Footer.

[ ] UI Kit: Componentizar botões, inputs e cards com estados de hover.

[ ] Framer Motion Setup: Definir variantes de animação padrão (FadeIn, SlideUp) para reuso.

[ ] Responsividade: Validar grid para Mobile, Tablet e Desktop.

🚀 Fase 3: Desenvolvimento de Seções (O Site)
Objetivo: Construir o conteúdo com foco em conversão e estética.

[ ] Hero Section: Texto de alto impacto, CTA principal e animação de entrada.

[ ] Seção Sobre/Serviços: Grid de cards com ícones (Lucide) e micro-interações.

[ ] Social Proof: Seção de depoimentos ou logotipos de clientes/parceiros.

[ ] Formulário de Contato: Validação de campos e integração (EmailJS ou API .NET 8).

[ ] Galeria/Portfólio: Otimização de imagens com Lazy Loading.

🔍 Fase 4: SEO & Performance (O Polimento)
Objetivo: Ser amado pelo Google e carregar instantaneamente.

[ ] SEO Técnico: Configurar react-helmet para Meta Tags dinâmicas e OpenGraph (preview redes sociais).

[ ] Asset Optimization: Converter imagens para WebP e comprimir SVGs.

[ ] Lighthouse Audit: Chegar aos 95+ pontos em Performance, Acessibilidade e SEO.

[ ] Sitemap & Robots: Gerar arquivos para indexação.

🏁 Fase 5: Launch & Feedback
Objetivo: Publicação oficial e monitoramento.

[ ] Domínio Customizado: Apontar DNS e configurar SSL (HTTPS).

[ ] Analytics: Configurar Google Analytics ou Vercel Insights.

[ ] Final Check: Testar em diferentes navegadores (Chrome, Safari, Firefox).
